**Product owner ruling on U-1 (recorded 2026-11-08, given in chat by the Story's product owner, sbruhov@gmail.com).** The only entry not present at the baseline is a scrollbar produced by fully invisible elements (hover tooltips with `opacity: 0` and `visibility: hidden`); there is no content a user would have to scroll to, so it is a visual CSS artefact and not unreachable content. The 256 px / `seo-generator` scrollbar must be re-measured in phase 2 (T7) after the fix; phase 2 (13 modes, both rail states, the real rail) is still to be measured, so the FR-16 line below records the owner's reading of U-1 and the phase-1 outcome, not a completed FR-16 measurement.
