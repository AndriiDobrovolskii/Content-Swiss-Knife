**Changes in Story v5 against v4, as consumed here.**
- AC-5: an "edit" is a send with an earlier version attached through "Edit this →"; a quick-edit chip send or a typed follow-up stores no source version and shows neither the chip nor the control (ruling SQ-7-A, OD-35).
- AC-6: the truncation rule is deterministic - cut before the last hyphen within the first 41 characters so the result has at most 40, else hard cut at 40 (the owner ruling on Q5; OD-26 RESOLVED).
- AC-11: the send button is enabled exactly when `canSend()`; an images-only send stays possible; "Write a prompt to start" only when there is nothing to send (ruling SQ-1-B, OD-29).
- AC-13a: `durationMs` runs from the Send or Retry click to the hand-off of the response to the persistence port; the write and the attachment upload are not included (ruling SQ-6-A + SQ-6-U1, OD-34).
- AC-15: two further permitted test changes (the SQ-5 dispositions, with the delivery and archive tests kept as native-delivery tests and the images-only-send tests changing only their lookup name; the narrowing of the one assertion that counts generated images in the feed).
- Q5 closed ("No open question remains"); a Context sentence records the owner rulings (images-only send possible, picked preset id still sent, model text interleaved, `role="log"` kept, tests kept as native-delivery tests, `durationMs` end point, only a send with a version attached is an edit).
