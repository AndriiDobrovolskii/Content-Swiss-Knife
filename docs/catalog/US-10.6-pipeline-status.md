## T7 notes for later tasks

- `fan-out.js` exports `runSlots({ granted, call, sleep, signal, requestCarriedFileUri })` and `reduceSlots({ slots, requested, unitPrice })`. `runSlots` never rejects; it returns `[{ index, outcome }]` in slot order. `call(index)` is ONE attempt: T8 passes `() => logged(log, 'generate', () => gemini.generateImage({...}))`, and `runSlots` wraps it in `runWithRetry` (so `logged` stays private to `handlers.js`).

- An `images` outcome also carries the raw `usageMetadata`, so T8 can build each slot's usage row with the unchanged `buildUsageRow`; the slot's `usage` (summed by `reduceSlots`) is derived through `buildUsageRow` too, so the two cannot disagree.
- When no slot succeeded, `reduceSlots` returns `{ class: 'safety' | 'text' | 'failed' }` for the lowest slot or rethrows its error; the handler turns `failed` into `EMPTY_RESPONSE`, as today.
- Smoke-checked outside the suite (no test added): three parallel calls with one non-retryable 400 gave `succeeded 2`, `costUsd 0.08`, `failures [{ cause: 'retries_exhausted' }]`. `runSlots` has no spec of its own in T7's named tests; T8's handler specs exercise it.
