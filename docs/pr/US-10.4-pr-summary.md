## Body

```markdown
Closes US-10.4 - Redesign the app shell: grouped, collapsible navigation and restyled layout in light and dark themes (part 1 of 3 of the Image Studio redesign; US-10.5 and US-10.6 follow and are not in this PR).

## What changed

The two navigation surfaces of the old shell - the sidebar header and the in-panel Mode Switcher - are replaced by one left navigation rail: three collapsible groups (SEO & Text 9, Images 2, Code 1), the Dashboard and the Language, Theme and AI Settings controls at the bottom, and a collapse control that turns it into a 64 px icon-only rail (state persisted under `seo_gen_shell_rail_expanded`, expanded by default, storage failures never reach the click handler). The input panel is now rendered only in the nine text modes and Image Tools; Image Studio, HTML Editor and the Dashboard get the full width, and Clear All, History and the improvement-request block go with the panel. The shell surfaces take eight colour tokens (dark `#0b1120` page, `#111a2e` rail, `#26324a` border, `#7c3aed` accent on the active icon and left border only) with light counterparts.

## Why

The Mode Switcher sat inside the input panel, so modes that have no input panel (Image Studio, HTML Editor, Dashboard) still carried one, and the header controls competed with the panel for the same 384 px. The redesign follows the product owner's design (boards "Active session" and "Empty state") and lays the ground for the Image Studio Stories. Evidence: `docs/stories/US-10.4-app-shell-redesign.md` (v4), `docs/specifications/US-10.4-spec.md` (v2, APPROVED).
```
