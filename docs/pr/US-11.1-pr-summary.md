## What changed

The AI Model Settings now offer, for provider Gemini in both the Deep and the Fast slot, exactly four models in this order: Gemini 4 Carbon, Gemini 3.1 Pro, Gemini 4 Hydrogen, Gemini 3.8 Flash. Gemini 3.7 Flash and Gemini 3.6 Flash are gone from the catalog, the dropdowns, the prices and the active docs. Selecting Carbon or Hydrogen in a dropdown sets that model's default level (Carbon `medium`, Hydrogen `high`); no Gemini 4 model offers `minimal`. Defaults are unchanged (Deep `claude-sonnet-5-5` at `high`, Fast `gemini-3.8-flash` at `low`). Both new models use `maxOutputTokens` 65536 in the catalog.

- **Retired-id migration.** A stored Deep or Fast slot holding `gemini-3.7-flash` or `gemini-3.6-flash` is restored in the browser as `gemini` / `gemini-3.8-flash` (stored `minimal` becomes `low`, `low` / `medium` / `high` kept, an absent level resolves to `high`) and persisted once. The server does the same in `resolveSlot` for a request that still carries a retired id (provider `gemini` only; one `console.warn` per call; level clamped). The existing `claude-sonnet-4-6` to `claude-sonnet-5-5` migration is unchanged. An unknown Gemini model id on the premium tier now falls back to Carbon (first premium catalog entry); this is documented in the code.
- **New `balanced` tier badge.** `ModelSpec.tier` becomes `'premium' | 'balanced' | 'fast'`. Hydrogen shows `$$ ⚡` in a sky colour set (light and dark variants), distinct from the amber (`$$$`, premium) and emerald (`$ ⚡`, fast) sets.
- **Pricing (`server/usage/pricing.js`).** Hydrogen is flat: 1.50 in / 7.50 out / 0 cache-write / 0.075 cache-read per 1M tokens. Carbon is date-dependent, evaluated on every lookup rather than at module load: introductory 2.00 / 10.00 / 0 / 0.10 for any instant before `2026-12-01T00:00:00Z` (UTC), and the standard price 4.00 / 20.00 / 0 / 0.20 from that exact instant on.
