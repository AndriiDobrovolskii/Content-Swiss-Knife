```markdown
Closes US-10.5 - Restyle Image Studio to the new design (header, session list, results feed, composer and empty state) without adding new capabilities. Part 2 of 3 of the Image Studio redesign (US-10.4, the app shell, is merged; US-10.6, new capabilities, follows and is not in this PR).

## What changed

Image Studio keeps every capability it had and is restyled onto the eight `--shell-*` tokens from US-10.4 in both themes. A studio header (title, "New session", a plain "history (N)" count) and a slim session list (name, local date, own cost) replace the old heading and cost line. The chat log is replaced by a feed of result cards: each card shows the input thumbnails, the prompt, ratio / resolution / model / preset chips, a "1 image - $0.12 - 12.4 s" summary and the text replies interleaved with the image tiles, plus a "Reuse prompt" button. Each image tile has a native one-click Download (the format selector is gone), Edit, and, for an edit whose source is retained, an "Edit of v1" chip with a keyboard-operable before/after compare slider in a full-view dialog. "Download all (N) .zip" names the archive `{timestamp}-{sessionName}.zip`. The empty state shows three starter preset cards (Product on white, Lifestyle scene, Category banner) read from `PROMPT_PRESETS`. The composer gets the quick-edit chips above the prompt, a Generate button with a `Ctrl Enter` hint driven by one `sendState`, and a preset check mark (`aria-pressed` plus a glyph). The local session store gains optional per-turn `cost`, `durationMs`, `presetId`, `inputRefs` and `editOfVersion`; sessions saved before this PR load unchanged.

## Why

The mockup (`Knowledge/Issues/5/Image Studio Redesign.html`) asks for a results feed that reads at a glance, a way to check what an edit changed, and a helpful empty state, while US-10.4 already moved the shell onto the new tokens. The Story is deliberately visual only: Upscale 4K, Variation, Alt text, Ctrl+K search, spend totals, Save-as-preset, Product/Style ref roles, the Images 1/2/4 selector and the pre-send estimate are not rendered. Evidence: `docs/stories/US-10.5-image-studio-visual-redesign.md` (v5), `docs/specifications/US-10.5-spec.md` (v4), and the owner decisions in `docs/decisions/US-10.5-open-decisions.md`.
```
