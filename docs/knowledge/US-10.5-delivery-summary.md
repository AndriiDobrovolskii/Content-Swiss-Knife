# US-10.5 delivery summary — Image Studio restyled onto the shell tokens: result-card feed, compare slider, starter cards

## What was delivered
Image Studio keeps every capability it had and is restyled onto the eight `--shell-*` tokens from US-10.4 in light and dark themes. Part 2 of 3 of the
Image Studio redesign (US-10.4, the app shell, is merged; US-10.6, new capabilities, is registered and not started). Angular track: no `server/`,
`src/domain`, `src/prompts`, `src/render`, `index.html`, `styles.css`, config, `.env.example` or FROZEN file changed.

- **Header and session list**: studio title, "New session" and a plain "history (N)" count; a slim session list (name, local `dd.MM . HH:mm` date,
  own cost).
- **Results feed**: the chat log became result cards. A card shows the input thumbnails, the prompt, ratio / resolution / model / preset chips, a
  "N image - $cost - seconds" summary, the text replies interleaved with the image tiles, and a **Reuse prompt** button. Reuse prompt counts as an
  edit: the preset check mark clears and the wire `presetId` is kept.
- **Image tile**: native one-click Download (the format selector is gone), Edit, and for an edit with a retained source an "Edit of v{N}" chip that opens
  a keyboard-operable before/after compare slider in a full-view dialog. "Download all (N) .zip" names the archive `{timestamp}-{sessionName}.zip`
  (fallback `{timestamp}-image-studio-versions.zip`). A version strip sits under the main image.
- **Composer and empty state**: quick-edit chips above the prompt, one `sendState` driving Generate, its `Ctrl Enter` hint and "Write a prompt to
  start", a preset check mark (`aria-pressed` plus glyph), three starter preset cards (Product on white, Lifestyle scene, Category banner) read from
  `PROMPT_PRESETS`, and a progress skeleton during the first generation. Exactly one `role="status"` region.
- **Stored sessions**: optional per-turn `cost`, `durationMs`, `presetId`, `inputRefs` and `editOfVersion`; sessions saved before load unchanged,
  an invalid new field is treated as absent. Preset names, descriptions and the lifestyle ratio changed; templates are byte-identical.
- **Hardening after SECURITY_REVIEW v1** (human-directed, tests first): NB-1 malformed stored base64 no longer throws in the render path, NB-2
  `inputRefs` is capped at read time (`MAX_INPUT_REFS = 10`), NB-3 a stored MIME outside png/jpeg/webp (`isImageMime`) cannot reach a `data:` URL
  or a delivered file. **Contrast fix** (T44): the attachment Retry label was `bg-amber-600` at 3.19:1, now `bg-amber-700 text-white` at 5.02:1.
