# Test strategy: US-10.6 (Image Studio new capabilities), v2

v1 ended `BLOCKED` on the vendor prices, the seams SM-1..SM-12, the UA copy and the placement. The owner's rulings of 2026-11-14 (Open Decisions v4, "Owner answers": OD-2 prices, OD-18 cost formula, the batch ruling G-2 A / G-6 / G-7 / G-8 / SM-1..SM-9, SM-12, UA copy, placement, the Product / Style ref toggle) and the vendor-facts evidence v1 clear those blockers. v2 replaces every former deferral by tests, adds the component specs, and lists the honest residual in section 6.

## 1. Triage rule

A case is written only when its expected value comes from the Story / Specification base text, the owner's rulings, the accepted plan DEFAULTs (G-8) or the evidence. A value the rulings do not give (for example the reason copy of a disabled already-4K Upscale) is not invented and is listed in section 6.

## 2. Levels, runners and what each file proves

Logic runner (`npm run test:logic`): pure modules, server, services (`Injector.create` with `import '@angular/compiler'` first, never TestBed), cross-runtime specs. Component runner (`npm run test:components`): `*.component.spec.ts` only, `@testing-library/angular`, queries by role and accessible name. Not-yet-existing modules, exports and tokens are reached through `load()` / dynamic `import()` or an `as any` cast, so `tsc --noEmit` stays at zero diagnostics and the component build compiles; each missing symbol is one named failure. (v2 note: `ng test` compiles every spec under `src/` together, so a static import of a missing symbol would have broken all 458 existing component tests.)

## 5. Determinism and safety

No `sleep`, no network, no unseeded randomness; completion order of parallel calls by deferred promises; time from the fake clock or an explicit `nowMs`; the component specs use the existing `settle()` flush and `vi.waitFor`. The `price` double of the handler specs is `unit x count` with a TEST unit; the production wiring cases use the REAL `computeImageCost`. No live Gemini call.
