## 6. Coverage gaps and caveats for the next stages

1. **Live smoke waived (OD-5).** A real Carbon call and a real Image Studio upload on SDK 2.32.0 are unverified; the PR must
   list them (plan F-10, review NB-6, risk K-8). No test covers the SDK's own continuation, timeouts or usage summing.
2. **`npm install` is required for one red test.** `node_modules holds a 2.x copy that is >= 2.32.0` fails until T1 installs the
   package, and stays valid for `npm ci`.
3. **FR-5 is verified by source scan, not by the compiler.** See the strategy, "Deviations" 1: a compile-time assertion
   stopped `ng test` from building, and the JSON is cast through `unknown`, so `tsc` cannot check a `balanced` entry.
4. **Naming convention for the builder (FR-30 recognition files).** In `src/services/model-settings.service.ts` and
   `server/providers/model-support.js` a retired name may appear only in a declaration whose constant name contains `retired` or
   `remap`, on a table-entry line starting with the quoted id, or on a comment that says retire, migrate or remap. The
   failure message prints file, line and text.
5. **Error text of the `CONTINUATION` guard.** The tests require the message to name the model, match
   `isUnrepairableGenerationError` (so it must read like `[gemini] <what> truncated: hit ... on <model>`), carry no `status`
   and contain none of the `withRetry` transient markers. The first is FR-23; the other three come from the approved plan D9
   item 2 and task breakdown T2, not from the Specification. The literal word `CONTINUATION` is deliberately NOT required
   (the plan gives it only as an example wording).
6. **A spy on `Storage.prototype.setItem` is unreliable here.** In happy-dom it does not see writes once a test has already
   called `localStorage.setItem`; the new tests spy on the `localStorage` instance. Existing storage-failure tests were left
   as they are.
7. **No corpus gap.** The Story changes no generated HTML, so the two-item corpus limitation noted in
   `test/render-reconciliation.report.md` does not apply.
8. **Nothing was skipped, weakened or excluded.** No test was deleted: the five retired-id assertions that expected the
   retired model to be selectable, priced, untouched or returned unchanged were inverted into their specified opposite
   (migrated / remapped / absent), and the "leaves minimal untouched" provider case was replaced as OD-8 allows.
